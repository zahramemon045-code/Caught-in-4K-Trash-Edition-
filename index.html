How objects map to waste classes

The model itself recognizes general objects, not waste categories — this table is what translates "banana" or "bottle" into a bin. Anything it detects that isn't on this list falls back to Other.

General-purpose object detection, not a model trained on trash specifically — it won't tell a soiled paper plate from a clean one, or a battery from a torch. For that level of accuracy you'd train a custom model (e.g. YOLOv8 on a labeled waste dataset via Roboflow) and export it to run in the browser. This gets a live camera and real bounding boxes working today, with the same six-class system as the rest of the site.
